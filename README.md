# 🕌 মাদ্রাসা ম্যানেজমেন্ট সিস্টেম (Madrasa Management System - MMS)

> **একটি আধুনিক, অফলাইন-সমর্থিত (PWA) পূর্ণাঙ্গ মাদ্রাসা প্রশাসন, তালীমী কার্যক্রম ও হিসাব অটোমেশন প্ল্যাটফর্ম।**  
> বাংলাদেশ ও আন্তর্জাতিক কওমি/আলিয়া মাদ্রাসার বাস্তব কার্যক্রম ও বেফাকুল মাদারিসিল আরাবিয়া (BEFAQ) মানদণ্ডে নির্মিত।

## 🌟 প্রধান মডিউল ও সুবিধাসমূহ (Key Features)

### ১. 🏠 ইন্টারেক্টিভ ড্যাশবোর্ড (Bento Dashboard)
- **রিয়েল-টাইম ক্যাশ ও ফি সামারি:** দৈনিক আয়, মাসিক ফি সংগ্রহ, মোট বকেয়া এবং মেস ব্যয়ের সংক্ষিপ্ত বিবরণ।
- **ম্যাজিক ইউআই (Magic UI) স্পটলাইট ইফেক্ট:** মাউস ট্র্যাকিং হোভার এফেক্ট ও আধুনিক ইসলামিক প্যালেট (Deep Teal, Emerald, Gold)।
- **তালীমী ও প্রশাসনিক কুইক অ্যাকশন:** এক ক্লিকে ফি আদায়, নতুন ভর্তি, সবক ও নোটিশ প্রবেশ।

### ২. 👨‍🎓 শিক্ষার্থী ও ভর্তি ব্যবস্থাপনা (Student Management)
- আবাসিক, অনাবাসিক ও ডে-কেয়ার ছাত্রদের প্রোফাইল সংরক্ষণ।
- রোল নম্বর, বিভাগ (হিফজ, কিতাব, নূরানী), অভিভাবকের ফোন নম্বর ও বকেয়ার রেকর্ড।
- **প্রিন্ট রেডি কালার আইডি কার্ড (Student ID Card):** বারকোড ও মুহতামিমের সিল-স্বাক্ষর সহ।

### ৩. 💰 ফি আদায় ও ডিজিটাল রসিদ (Fee Collection & POS)
- পিওএস (POS) দ্রুত ফি আদায় মোডাল।
- নগদ, বিকাশ, নগদ ও ব্যাংক পেমেন্ট মেথড সাপোর্ট।
- **২-কপি মানি রিসিট (Money Receipt):** 'ছাত্র কপি' এবং 'অফিস কপি' সহ A4 প্রিন্টেবল রসিদ।

### ৪. 📒 ক্যাশ ও ডে-বুক লেজার (General Ledger)
- দৈনিক আয় ও ব্যয়ের হিসাব খতিয়ান।
- ফি আদায় ও মেস বাজার থেকে স্বয়ংক্রিয় ডাবল-এন্ট্রি ট্রানজেকশন জেনারেশন।

### ৫. 📖 দৈনিক সবক রেজিস্টার (Sabaq Log)
- হিফজ ও কিতাব বিভাগের জন্য বিশেষায়িত সবক মূল্যায়ন।
- **নতুন সবক (আজকের পাঠ), সবক সাবেক (পেছনের রিভিশন)** এবং **আমোখতা/মানজিল** খাতা।
- ভুল সংখ্যা ও মানদণ্ড মূল্যায়ন (মুমতাজ, জায়্যিদ জিদ্দান, জায়্যিদ, মাকবুল)।

### ৬. 📅 ডিজিটাল হাজিরা খাতা (Attendance Register)
- শিক্ষার্থী এবং সম্মানিত শিক্ষক/কর্মচারীদের আলাদা হাজিরা ট্র্যাকার।
- এক ক্লিকে "✓ সবাই উপস্থিত", অনুপস্থিতি, ছুটি ও বিলম্বে আগমনের হিসাব।

### ৭. 🎉 অনুষ্ঠান, ওয়াজ মাহফিল ও উৎসব (Events & Festivals)
- বার্ষিক ইসলামী মহাসম্মেলন, খতমে বুখারী ও দস্তারবন্দী পাগড়ী বিতরণ সমাবর্তন।
- কুরআন ক্বিরাত প্রতিযোগিতা ও রমজানের ইফতার মাহফিলের বাজেট ও অতিথি ট্র্যাকার।

### ৮. 📢 প্রাতিষ্ঠানিক নোটিশ বোর্ড (Notice Board)
- পরীক্ষা, ছুটি ও শূরার জরুরি নোটিশ।
- **মাদ্রাসার অফিশিয়াল প্যাডে নোটিশ প্রিন্ট** সুবিধা।

### ৯. 📝 পরীক্ষা ও ফলাফল (BEFAQ Standard Results)
- ১ম সাময়িক, ২য় সাময়িক ও বার্ষিক পরীক্ষার বিষয়ভিত্তিক নম্বর এন্ট্রি।
- বেফাকুল মাদারিসিল আরাবিয়া গ্রেডিং (মুমতাজ, জায়্যিদ জিদ্দান, জায়্যিদ, মাকবুল, রাসিব)।
- একাডেমিক মার্কশিট (Marksheet) প্রিভিউ ও সরাসরি প্রিন্ট।

### ১০. 👨‍🏫 শিক্ষক ও স্টাফ বেতন পে-রোল (Staff Payroll)
- শিক্ষক ও কর্মচারীদের মূল বেতন, বাড়িভাড়া ও খাবার ভাতা হিসাব।
- বেতন পরিশোধের সাথে সাথে জেনারেল লেজারে ভাউচার এন্ট্রি এবং অফিসিয়াল **Pay Slip** প্রিন্ট।

### ১১. 📚 কিতাবখানা ও লাইব্রেরি (Library Management)
- বুখারী, মুসলিম, হিদায়া, কুদূরী সহ ইসলামী কিতাবসমূহের ক্যাটালগ ও শেলফ ট্র্যাকিং।
- ছাত্র ও শিক্ষকদের কিতাব ইস্যু ও ফেরত রেজিস্টার।

### ১২. 🍽️ লিল্লাহ বোর্ডিং ও মেস খতিয়ান (Boarding Mess)
- আবাসিক ছাত্রদের দৈনন্দিন মিল ও বাজার খরচের হিসাব।

### ১৩. 💳 মহাজন দেনা-পাওনা লেজার (Dena-Paona Tracker)
- মুদি দোকান, হার্ডওয়্যার বা লাইব্রেরির বকেয়া দেনা-পাওনা ট্র্যাকিং ও কিস্তিতে পরিশোধ।

### ১৪. 👨‍👩‍👧 নো-পাসওয়ার্ড অভিভাবক পোর্টাল (Guardian Portal)
- কোনো জটিল পাসওয়ার্ড ছাড়াই মাদ্রাসার কোড ও রোল নম্বর দিয়ে অভিভাবকরা সন্তানের ফি ও সবক দেখতে পারেন।

## 🛠️ টেকনোলজি স্ট্যাক (Tech Stack)

| প্রযুক্তি | কাজ |
|---|---|
| **React 18 + TypeScript** | হাই-পারফরম্যান্স ফ্রন্টএন্ড কোর ও স্ট্রং টাইপ সেফটি |
| **Vite 5** | অতি দ্রুত বিল্ড ও লাইভ ডেভ সার্ভার |
| **Tailwind CSS 3** | কাস্টম ইসলামিক কালার প্যালেট ও রেসপন্সিভ ডিজাইন |
| **PWA (Progressive Web App)** | অফলাইন সাপোর্ট ও মোবাইল হোম-স্ক্রিন ইনস্টলেশন |
| **Lucide React** | আধুনিক লাইটওয়েট ভেক্টর আইকন সেট |
| **LocalStorage Engine** | শূন্য ব্যাকএন্ড নির্ভরতা — ব্রাউজারেই নিরাপদ ডাটা স্টোরেজ |

## 🚀 লোকালি চালানোর নিয়মাবলী (How to Run Locally)

### পূর্বশর্ত:
- [Node.js](https://nodejs.org/) (সংস্করণ ১৮ বা তার পরবর্তী)

### কমান্ডসমূহ:

```bash
# ১. রিপোজিটরি ক্লোন করুন
git clone https://github.com/hmkborhanuddin2004-tech/madrasa-management-system.git

# ২. প্রজেক্ট ফোল্ডারে প্রবেশ করুন
cd madrasa-management-system

# ৩. ডিপেনডেন্সি ইনস্টল করুন
npm install

# ৪. ডেভেলপমেন্ট সার্ভার চালু করুন
npm run dev

# ৫. প্রোডাকশন বিল্ড তৈরি করুন
npm run build
```

ব্রাউজার খুলে ভিজিট করুন: `http://localhost:3000` (বা টার্মিনালে প্রদর্শিত পোর্টে)।

## 🛡️ সাইবার সিকিউরিটি অডিট রিপোর্ট (Security Audit)

- **Semgrep SAST (লেভেল ১):** ✅ সোর্স কোডে কোনো হার্ডকোডেড সিক্রেট, এক্সএসএস বা দুর্বলতা নেই (০ ইস্যু)।
- **Trivy SCA (লেভেল ১):** ✅ সমস্ত থার্ড-পার্টি লাইব্রেরিতে ০টি হাই/ক্রিটিক্যাল CVE।
- **Nuclei DAST + Strix (লেভেল ২):** ✅ লাইভ সার্ভারে Clickjacking প্রোটেকশন (`X-Frame-Options: SAMEORIGIN`) এবং সেনসিটিভ ফাইল ব্লকিং সক্রিয়।
